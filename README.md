# Code and Data for the HESS Manuscript

This repository contains the release data and R scripts used for the two Bayesian
cumulative link mixed model (CLMM) analyses reported in the associated manuscript.

## Associated Manuscript

**Title:** *Sparse validation can mask process errors in urban flood modelling:
evidence from large multimodal model-assisted video observations*

**Authors:** Shunan Zhou, Heng Lyu, Anette Eltner, Pedro Zamboni, Nan Wang,
Jiaxing Zhao, and Chi Zhang

**Journal:** Hydrology and Earth System Sciences (HESS)

**Article DOI:** Pending

**Archived code-and-data version:** `v1.0.0` (Zenodo DOI pending)

## Scope

The release supports the flood-phase discrepancy model and the rainfall--site
discrepancy model described in the manuscript. The internal script and output names
retain the following mappings:

- `phase_diagnostic` / `clmm_phase_0410`: flood-phase discrepancy model;
- `conditional_discrepancy` / `clmm_explain_0410`: rainfall--site discrepancy model.

The repository includes:

- 36,490 expert-verified, minute-level ordinal inundation observations from five
  rainfall events;
- 20,825 observation--simulation pairs from 60 monitored sites within the modelled
  drainage districts;
- scripts for fitting and evaluating the two CLMMs;
- a data dictionary and a record of the tested software environment.

Raw surveillance videos and precise monitoring-site coordinates are not included.

## Repository Layout

```text
code/
  01_fit_phase_diagnostic_clmm.R
  01_evaluate_phase_diagnostic_clmm.R
  01_fit_conditional_discrepancy_clmm.R
  01_evaluate_conditional_discrepancy_clmm.R
  utils_clmm_release.R
data/
  clmm_model_input_v0410.csv
  observed_flood_levels_v0308.csv
docs/
  data_dictionary.md
  environment.md
results/
  .gitkeep
```

The `results/` directory is the default location for fitted objects, diagnostic
files, tables, and figures generated by the scripts. Generated results are ignored
by Git.

## Data Files

- `data/observed_flood_levels_v0308.csv` contains the complete set of retained
  expert-verified ordinal observations. It contains 36,490 records from 222
  event-specific camera records at 124 monitored sites.
- `data/clmm_model_input_v0410.csv` contains the 20,825 complete
  observation--simulation pairs used by both CLMM analyses.

Column definitions, units, identifiers, event dates, and filtering rules are provided
in `docs/data_dictionary.md`.

## Software Requirements

The release was tested with R 4.5.2, `cmdstanr` 0.8.0, and CmdStan 2.38.0 on
Apple silicon macOS. Installation details and package versions are listed in
`docs/environment.md`.

## Quick Start

Run all commands from the repository root.

First, verify data preparation without fitting either model:

```bash
CLMM_PREP_ONLY=TRUE Rscript code/01_fit_phase_diagnostic_clmm.R
CLMM_PREP_ONLY=TRUE Rscript code/01_fit_conditional_discrepancy_clmm.R
```

Fit and evaluate both models:

```bash
Rscript code/01_fit_phase_diagnostic_clmm.R
Rscript code/01_evaluate_phase_diagnostic_clmm.R

Rscript code/01_fit_conditional_discrepancy_clmm.R
Rscript code/01_evaluate_conditional_discrepancy_clmm.R
```

By default, the scripts read `data/clmm_model_input_v0410.csv`, write outputs to
`results/`, and use relative paths. Event 1 (12 August 2023) is explicitly used as
the event reference level in both fitted models.

## Configuration

The fitting scripts accept the following environment variables:

- `CLMM_DATA_FILE`
- `CLMM_RESULTS_ROOT`
- `CLMM_DO_FIT`
- `CLMM_PREP_ONLY`
- `CLMM_SEED`
- `CLMM_CHAINS`
- `CLMM_ITER`
- `CLMM_WARMUP`
- `CLMM_CORES`
- `CLMM_ADAPT_DELTA`
- `CLMM_MAX_TREEDEPTH`
- `CLMM_REFRESH`

The evaluation scripts accept:

- `CLMM_MODEL_RESULTS_ROOT`
- `CLMM_OUTPUT_RESULTS_ROOT`
- `CLMM_DO_LAYER1`
- `CLMM_DO_PPC`
- `CLMM_DO_LAYER3`
- `CLMM_DO_LOO`
- `CLMM_EVAL_NDRAWS`
- `CLMM_PPC_NDRAWS_PLOT`
- `CLMM_PPC_NDRAWS_TABLE`

For example:

```bash
CLMM_MODEL_RESULTS_ROOT=results/existing_fit \
CLMM_OUTPUT_RESULTS_ROOT=results/test_evaluation \
Rscript code/01_evaluate_phase_diagnostic_clmm.R
```
